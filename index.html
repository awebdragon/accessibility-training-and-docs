Internal Accessibility Testing Examples

Live examples for use during accessibility training. Each page is designed to be scanned with automated tools (axe, ANDI) to illustrate what those tools can and cannot catch.

  • Focus order false negative Scrambled tab order that automated tools won't flag.
  • Link Context false negative Same link text with different destinations causes ambiguous link failures.
  • Form Instructions & Errors How automated scans miss error and instruction association (both live and on-submit), or how they miss insufficient descriptions in errors and instructions.
